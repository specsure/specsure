    How it works

    1. ReadLocal variables, with their collections and modes, and local styles.
    2. SaveA .zip for a repository and CI, or one file for a quick check.
    3. UseDrop the file into Token Fix or Token Diff, or run the CLI on the folder.

    Where to take it

    Token Fix
    the token meant for a value, and what to replace in your code
    Token Diff
    two exports side by side: what changed, what breaks
    CLI
    checks in the terminalnpx @dsgraph/cli check tokens
    CI
    a report on every pull request: specsure/dsgraph-action

    Figma → DTCG

    Color
    color
    Number
    dimension in px for lengths (by scope or name), fontWeight, otherwise number
    String
    fontFamily for font families, fontWeight for font style names (Semi Bold → 600)
    Easing, timing
    cubicBezier, duration in ms
    Modes
    a modifier in the resolver, the default mode first
    Extension
    an extended collection: all it inherits, under its name, overrides applied
    Same names
    when two collections share names, each one's tokens go under its name
    Text style
    typography, bound variables as references
    Effect style
    shadow
    Grid style
    a group of count, gutter, offset and size per grid
    Library
    its value, the variable's name kept in $extensions

    Left out and listed after reading: booleans and plain strings, springs, blur effects, styles of several paints.
